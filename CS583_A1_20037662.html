2. Logistic regression model¶

The objective function is $Q (w; X, y) = \frac{1}{n} \sum_{i=1}^n \log \Big( 1 + \exp \big( - y_i x_i^T w \big) \Big) + \frac{\lambda}{2} \| w \|_2^2 $.

In [5]:
# Calculate the objective function value
# Inputs:
#     w: d-by-1 matrix
#     x: n-by-d matrix
#     y: n-by-1 matrix
#     lam: scalar, the regularization parameter
# Return:
#     objective function value (scalar)
def objective(w, x, y, lam):
    n, d = x.shape
    yx = numpy.multiply(y, x) # n-by-d matrix
    yxw = numpy.dot(yx, w) # n-by-1 matrix
    vec1 = numpy.exp(-yxw) # n-by-1 matrix
    vec2 = numpy.log(1 + vec1) # n-by-1 matrix
    loss = numpy.mean(vec2) # scalar
    reg = lam / 2 * numpy.sum(w * w) # scalar
    return loss + reg

3. Numerical optimization¶

3.1. Gradient descent¶

The gradient at $w$ is $g = - \frac{1}{n} \sum_{i=1}^n \frac{y_i x_i }{1 + \exp ( y_i x_i^T w)} + \lambda w$

In [7]:
# Calculate the gradient
# Inputs:
#     w: d-by-1 matrix
#     x: n-by-d matrix
#     y: n-by-1 matrix
#     lam: scalar, the regularization parameter
# Return:
#     g: g: d-by-1 matrix, full gradient
def gradient(w, x, y, lam):
    n, d = x.shape
    yx = numpy.multiply(y, x) # n-by-d matrix
    yxw = numpy.dot(yx, w) # n-by-1 matrix
    vec1 = numpy.exp(yxw) # n-by-1 matrix
    vec2 = numpy.divide(yx, 1+vec1) # n-by-d matrix
    vec3 = -numpy.mean(vec2, axis=0).reshape(d, 1) # d-by-1 matrix
    g = vec3 + lam * w
    return g
In [8]:
# Gradient descent for solving logistic regression
# Inputs:
#     x: n-by-d matrix
#     y: n-by-1 matrix
#     lam: scalar, the regularization parameter
#     stepsize: scalar
#     max_iter: integer, the maximal iterations
#     w: d-by-1 matrix, initialization of w
# Return:
#     w: d-by-1 matrix, the solution
#     objvals: a record of each iteration's objective value
def grad_descent(x, y, lam, stepsize, max_iter=100, w=None):
    n, d = x.shape
    objvals = numpy.zeros(max_iter) # store the objective values
    if w is None:
        w = numpy.zeros((d, 1)) # zero initialization
    
    for t in range(max_iter):
        objval = objective(w, x, y, lam)
        objvals[t] = objval
        print('Objective value at t=' + str(t) + ' is ' + str(objval))
        g = gradient(w, x, y, lam)
        w -= stepsize * g
    
    return w, objvals

3.2. Stochastic gradient descent (SGD)¶

Define $Q_i (w) = \log \Big( 1 + \exp \big( - y_i x_i^T w \big) \Big) + \frac{\lambda}{2} \| w \|_2^2 $.

The stochastic gradient at $w$ is $g_i = \frac{\partial Q_i }{ \partial w} = -\frac{y_i x_i }{1 + \exp ( y_i x_i^T w)} + \lambda w$.

In [10]:
# Calculate the objective Q_i and the gradient of Q_i
# Inputs:
#     w: d-by-1 matrix
#     xi: 1-by-d matrix
#     yi: scalar
#     lam: scalar, the regularization parameter
# Return:
#     obj: scalar, the objective Q_i
#     g: d-by-1 matrix, gradient of Q_i
def stochastic_objective_gradient(w, xi, yi, lam):
    yx = yi * xi # 1-by-d matrix
    yxw = float(numpy.dot(yx, w)) # scalar
    
    # calculate objective function Q_i
    loss = numpy.log(1 + numpy.exp(-yxw)) # scalar
    reg = lam / 2 * numpy.sum(w * w) # scalar
    obj = loss + reg
    
    # calculate stochastic gradient
    g_loss = -yx.T / (1 + numpy.exp(yxw)) # d-by-1 matrix
    g = g_loss + lam * w # d-by-1 matrix
    
    return obj, g
In [11]:
# SGD for solving logistic regression
# Inputs:
#     x: n-by-d matrix
#     y: n-by-1 matrix
#     lam: scalar, the regularization parameter
#     stepsize: scalar
#     max_epoch: integer, the maximal epochs
#     w: d-by-1 matrix, initialization of w
# Return:
#     w: the solution
#     objvals: record of each iteration's objective value
def sgd(x, y, lam, stepsize, max_epoch=100, w=None):
    n, d = x.shape
    objvals = numpy.zeros(max_epoch) # store the objective values
    if w is None:
        w = numpy.zeros((d, 1)) # zero initialization
    
    for t in range(max_epoch):
        # randomly shuffle the samples
        rand_indices = numpy.random.permutation(n)
        x_rand = x[rand_indices, :]
        y_rand = y[rand_indices, :]
        
        objval = 0 # accumulate the objective values
        for i in range(n):
            xi = x_rand[i, :] # 1-by-d matrix
            yi = float(y_rand[i, :]) # scalar
            obj, g = stochastic_objective_gradient(w, xi, yi, lam)
            objval += obj
            w -= stepsize * g
        
        stepsize *= 0.9 # decrease step size
        objval /= n
        objvals[t] = objval
        print('Objective value at epoch t=' + str(t) + ' is ' + str(objval))
    
    return w, objvals

6.1. Compute the objective $Q_I$ and its gradient using a batch of samples¶

Define $Q_I (w) = \frac{1}{b} \sum_{i \in I} \log \Big( 1 + \exp \big( - y_i x_i^T w \big) \Big) + \frac{\lambda}{2} \| w \|_2^2 $, where $I$ is a set containing $b$ indices randomly drawn from $\{ 1, \cdots , n \}$ without replacement.

The stochastic gradient at $w$ is $g_I = \frac{\partial Q_I }{ \partial w} = \frac{1}{b} \sum_{i \in I} \frac{- y_i x_i }{1 + \exp ( y_i x_i^T w)} + \lambda w$.

In [17]:
# Calculate the objective Q_I and the gradient of Q_I
# Inputs:
#     w: d-by-1 matrix
#     xi: b-by-d matrix
#     yi: b-by-1 matrix
#     lam: scalar, the regularization parameter
#     b: integer, the batch size
# Return:
#     obj: scalar, the objective Q_i
#     g: d-by-1 matrix, gradient of Q_i
def mb_stochastic_objective_gradient(w, xi, yi, lam, b):
    
    yx = numpy.multiply(yi, xi) 
    yxw = numpy.dot(yx, w) 

    loss = numpy.mean(numpy.log(1 + numpy.exp(-yxw)))
    reg = lam / 2 * numpy.sum(w * w)
    obj = loss + reg
    
    vec = numpy.divide(yx, 1 + numpy.exp(yxw))
    g_loss = -numpy.mean(vec, axis=0).reshape(-1, 1)
    g = g_loss + lam * w
    
    return obj, g

6.2. Implement mini-batch SGD¶

Hints:

  1. In every epoch, randomly permute the $n$ samples (just like SGD).
  2. Each epoch has $\frac{n}{b}$ iterations. In every iteration, use $b$ samples, and compute the gradient and objective using the mb_stochastic_objective_gradient function. In the next iteration, use the next $b$ samples, and so on.

# Mini-Batch SGD for solving logistic regression
# Inputs:
#     x: n-by-d matrix
#     y: n-by-1 matrix
#     lam: scalar, the regularization parameter
#     b: integer, the batch size
#     stepsize: scalar
#     max_epoch: integer, the maximal epochs
#     w: d-by-1 matrix, initialization of w
# Return:
#     w: the solution
#     objvals: record of each iteration's objective value
def mb_sgd(x, y, lam, b, stepsize, max_epoch=100, w=None):
    n, d = x.shape
    objvals = numpy.zeros(max_epoch)
    if w is None:
        w = numpy.zeros((d, 1))
        
    for t in range(max_epoch):
        rand_indices = numpy.random.permutation(n)
        x_rand, y_rand = x[rand_indices, :], y[rand_indices, :]
        
        objval_epoch = 0
        num_batches = n // b
        
        for i in range(num_batches):
            start, end = i * b, (i + 1) * b
            xi, yi = x_rand[start:end, :], y_rand[start:end, :]
            
            obj, g = mb_stochastic_objective_gradient(w, xi, yi, lam, b)
            objval_epoch += obj
            w -= stepsize * g
            
        stepsize *= 0.9
        objval_epoch /= num_batches
        objvals[t] = objval_epoch
        print('Objective value at epoch t=' + str(t) + ' is ' + str(objval_epoch))
        
    return w, objvals

def mb_sgd_momentum(x, y, lam, b, stepsize, beta=0.9, max_epoch=100, w=None):
    n, d = x.shape
    objvals = numpy.zeros(max_epoch)
    if w is None:
        w = numpy.zeros((d, 1))
    z = numpy.zeros((d, 1)) 
    
    for t in range(max_epoch):
        rand_indices = numpy.random.permutation(n)
        x_rand, y_rand = x[rand_indices, :], y[rand_indices, :]
        objval_epoch = 0
        num_batches = n // b
        for i in range(num_batches):
            start, end = i * b, (i + 1) * b
            xi, yi = x_rand[start:end, :], y_rand[start:end, :]
            obj, g = mb_stochastic_objective_gradient(w, xi, yi, lam, b)
            objval_epoch += obj
            
            z = beta * z + g
            w -= stepsize * z
            
        stepsize *= 0.9
        objval_epoch /= num_batches
        objvals[t] = objval_epoch
    return w, objvals

📝 Final Analysis & Theoretical Extensions¶

1. Empirical Performance Comparison (P1 & P3)¶

1. Empirical Performance Comparison (P1 & P3)¶

Based on the optimization curves generated from our experiment, we can observe distinct convergence behaviors among the algorithms:

  • Gradient Descent (Blue dashed line): It provides the most stable descent path but is the slowest to reach the minimum. This is expected because it evaluates the exact full gradient across all 640 training samples, resulting in only one parameter update per epoch. (Note: While the theoretical PDF refers to the full 768-sample dataset, our notebook partitions the data into 640 training and 128 test samples.)
  • Stochastic Gradient Descent (Red solid line): It shows an extremely steep initial drop, going from >0.64 down to <0.50 within just a few epochs. However, relying on a single sample makes the gradient estimate highly noisy, leading to significant zig-zag oscillations as it approaches the optimum.
  • MB-SGD with b=8 (Green solid line): This method strikes an excellent balance. By averaging gradients over a small batch, it drastically reduces variance while maintaining a high update frequency (80 updates per epoch). Consequently, it achieves the lowest objective value (~0.4767) among all tested configurations after 100 epochs.
  • MB-SGD with b=64 (Magenta solid line): This yields the smoothest curve among the stochastic methods, starting from ~0.6490. However, its descent is noticeably slower than (b=8). Because fewer updates are performed per epoch ((n/b=10) iterations), it only reaches an objective value of ~0.4880 by epoch 100.
  • MB-SGD with Momentum (Cyan solid line): Adding momentum significantly accelerates convergence. The momentum term smooths out the update direction, allowing the algorithm to take larger, more consistent steps toward the global minimum.

Conclusion: Unlike full-batch GD which takes exact steps, the convergence of MB-SGD depends heavily on the batch size and the total number of updates within a fixed epoch budget. While all algorithms steadily descend, MB-SGD with (b=8) clearly outperforms (b=64) in this experiment, reaching a lower objective value (~0.4767) much faster due to its higher update frequency per epoch.

2. Mathematical Derivations (P4 & P5)¶

P4. Calculating the Second Derivative of the Loss Term We aim to find the $d \times d$ matrix resulting from $\frac{\partial}{\partial \mathbf{w}} \left( \frac{\partial l_i}{\partial \mathbf{w}} \right)$. For simplicity, let $z = y_i \mathbf{w}^T \mathbf{x}_i$. The first derivative is: $$ \frac{\partial l_i}{\partial \mathbf{w}} = -y_i \mathbf{x}_i \cdot (1 + e^z)^{-1} $$ Applying the product rule and chain rule to differentiate with respect to $\mathbf{w}$: $$ \frac{\partial}{\partial \mathbf{w}} \left( -y_i \mathbf{x}_i (1 + e^z)^{-1} \right) = -y_i \mathbf{x}_i \cdot \frac{\partial}{\partial z} \left( (1 + e^z)^{-1} \right) \cdot \frac{\partial z}{\partial \mathbf{w}} $$ Since $\frac{\partial}{\partial z} (1 + e^z)^{-1} = \frac{-e^z}{(1 + e^z)^2}$ and $\frac{\partial z}{\partial \mathbf{w}} = y_i \mathbf{x}_i^T$: $$ = -y_i \mathbf{x}_i \cdot \left( \frac{-e^z}{(1 + e^z)^2} \right) \cdot y_i \mathbf{x}_i^T $$ Because labels $y_i$ are either $+1$ or $-1$, $y_i^2 = 1$. Thus, the local Hessian component is: $$ \mathbf{H}_i = \frac{e^{y_i \mathbf{w}^T \mathbf{x}_i}}{(1 + e^{y_i \mathbf{w}^T \mathbf{x}_i})^2} \mathbf{x}_i \mathbf{x}_i^T $$

P5. Constructing the Hessian Matrix of the Objective Function The overall Hessian $\nabla^2 Q(\mathbf{w})$ is the aggregation of the individual loss Hessians plus the regularization term. Differentiating the objective function $Q$ twice yields: $$ \nabla^2 Q(\mathbf{w}) = \frac{1}{n} \sum_{i=1}^{n} \left[ \frac{e^{y_i \mathbf{w}^T \mathbf{x}_i}}{(1 + e^{y_i \mathbf{w}^T \mathbf{x}_i})^2} \mathbf{x}_i \mathbf{x}_i^T \right] + \lambda \mathbf{I} $$ (Note: The scalar coefficient is strictly positive, and the outer product $\mathbf{x}_i \mathbf{x}_i^T$ is positive semi-definite. Adding $\lambda \mathbf{I}$ for $\lambda > 0$ ensures the entire Hessian is positive definite, proving strict convexity).

3. Hyperparameter Tuning Strategy (P6)¶

Instead of relying on a fixed regularization strength, a more robust approach involves 5-fold cross-validation. The procedure is as follows:

  1. Split the training data into 5 equal-sized folds.
  2. For a given candidate $\lambda$ (e.g., from $10^{-10}$ to $10^2$), train the logistic regression model on 4 folds and evaluate the classification error on the remaining validation fold.
  3. Rotate the validation fold until every fold has served once, then compute the average validation error: $E = \frac{1}{5} \sum_{k=1}^5 E_k$.
  4. Select the $\lambda$ that minimizes $E$.

While I implemented this logic in the notebook, initial runs indicated that the validation error is relatively flat across the range of $10^{-6}$ to $10^{-3}$. Because the regularization does not heavily restrict the model on this dataset, the baseline $\lambda = 10^{-6}$ was retained for consistency in the SGD experiments.
